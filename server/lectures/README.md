# Приложение Lectures

Приложение для управления мини-лекциями, привязанными к узлам (Node) и концептам (Concept) графа знаний.

## Возможности

-   ✅ Создание и редактирование лекций с богатым текстовым контентом
-   ✅ Поддержка изображений через inline WYSIWYG редактор (TinyMCE)
-   ✅ Поддержка LaTeX формул
-   ✅ Интеграция с VK видео
-   ✅ Привязка к одной сущности (Node или Concept)
-   ✅ API для фронтенда
-   ✅ Админка с предварительным просмотром

## Модель Lecture

### Основные поля:

-   `title` - название лекции
-   `content` - HTML контент с поддержкой изображений и формул
-   `node` - привязка к узлу графа (опционально)
-   `concept` - привязка к концепту (опционально)
-   `vk_video_url` - ссылка на видео VK
-   `vk_video_title` - название видео
-   `order` - порядок отображения
-   `is_active` - активность лекции

### Ограничения:

-   Лекция может быть привязана только к одной сущности (либо Node, либо Concept)
-   Поддерживаются только ссылки на видео VK в определенном формате

## API Endpoints

### Основные endpoints:

-   `GET /api/lectures/` - список всех лекций
-   `POST /api/lectures/` - создание новой лекции
-   `GET /api/lectures/{id}/` - получение лекции по ID
-   `PUT /api/lectures/{id}/` - обновление лекции
-   `DELETE /api/lectures/{id}/` - удаление лекции

### Специальные endpoints:

-   `GET /api/lectures/by_node/?node_id={id}` - лекции для конкретного узла
-   `GET /api/lectures/by_concept/?concept_id={id}` - лекции для конкретного концепта
-   `GET /api/lectures/{id}/with_entity_info/` - лекция с подробной информацией о сущности

### Фильтрация:

-   `?entity_type=node` - только лекции, привязанные к узлам
-   `?entity_type=concept` - только лекции, привязанные к концептам
-   `?is_active=true` - только активные лекции
-   `?node={id}` - лекции для конкретного узла
-   `?concept={id}` - лекции для конкретного концепта

### Поиск:

-   `?search={query}` - поиск по названию и содержимому

### Сортировка:

-   `?ordering=title` - по названию
-   `?ordering=order` - по порядку
-   `?ordering=created_at` - по дате создания

## Загрузка изображений

### Endpoint:

-   `POST /api/lectures/upload-image/`

### Поддерживаемые форматы:

-   JPEG (.jpg, .jpeg)
-   PNG (.png)
-   GIF (.gif)
-   WebP (.webp)

### Ограничения:

-   Максимальный размер файла: 5MB
-   Изображения сохраняются в `media/lectures/images/`

## LaTeX формулы

### Поддерживаемые форматы:

-   Инлайн формулы: `\(formula\)`
-   Блочные формулы: `\[formula\]`

### Примеры:

```latex
Инлайн: \(E = mc^2\)
Блочная: \[F = G\frac{m_1 m_2}{r^2}\]
```

## VK видео

### Поддерживаемые форматы ссылок:

-   `https://vk.com/video-123456_789012`
-   `https://vk.com/video123456_789012`
-   `https://vk.com/clip-123456_789012`

### Автоматическое преобразование:

-   Ссылки автоматически преобразуются в embed код
-   Поддерживается HD качество
-   Включены все необходимые разрешения (autoplay, fullscreen, etc.)

## Админка

### Особенности:

-   WYSIWYG редактор TinyMCE для поля content
-   Предварительный просмотр VK видео
-   Цветовая индикация типа связанной сущности
-   Оптимизированные запросы с select_related
-   Поддержка фильтрации и поиска

### Настройка TinyMCE:

-   Загрузка изображений через drag&drop
-   Кнопка для вставки LaTeX формул
-   Поддержка русского языка
-   Адаптивная высота редактора

## Использование

### Создание лекции через API:

```python
import requests

data = {
    'title': 'Введение в кинематику',
    'content': '<p>Кинематика изучает движение тел...</p>',
    'node': 1,  # ID узла
    'vk_video_url': 'https://vk.com/video-123456_789012',
    'order': 1,
    'is_active': True
}

response = requests.post('http://localhost:8000/api/lectures/', json=data)
```

### Получение лекций для узла:

```python
response = requests.get('http://localhost:8000/api/lectures/by_node/?node_id=1')
lectures = response.json()
```
