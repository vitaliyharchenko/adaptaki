## Фикстуры

Файл `fixtures.py` содержит вспомогательные функции для создания тестовых данных:

### Основные фикстуры:

-   `create_test_user()` - создание тестового пользователя
-   `create_test_superuser()` - создание тестового суперпользователя
-   `get_authenticated_client()` - аутентифицированный API клиент
-   `get_token_authenticated_client()` - клиент с JWT токеном

### Данные для тестов:

-   `get_valid_user_data()` - валидные данные пользователя
-   `get_invalid_user_data()` - невалидные данные пользователя
-   `get_update_user_data()` - данные для обновления
-   `get_token_data()` - данные для получения токена
-   `get_invalid_token_data()` - невалидные данные для токена

## Запуск тестов

### Запуск всех тестов приложения:

```bash
docker-compose exec web python manage.py test users -v 2
```

### Запуск конкретного теста:


## Настройки тестирования

### Тестовая база данных

Тесты используют in-memory SQLite базу данных (`:memory:`), что обеспечивает:

-   Быстрое выполнение тестов
-   Изоляцию тестов друг от друга
-   Автоматическую очистку после каждого теста

### Оптимизации для тестов

-   MD5 хешер паролей для ускорения
-   Отключенное кэширование
-   Отключенное логирование
-   Короткое время жизни JWT токенов (1 минута)

## Добавление новых тестов

При добавлении новой функциональности рекомендуется:

1. Создать тест в соответствующем классе
2. Использовать фикстуры из `fixtures.py`
3. Следовать паттерну: setup → action → assertion
4. Добавить описание теста на русском языке
5. Запустить тесты для проверки

Пример:

```python
def test_new_feature(self):
    """Тест новой функциональности"""
    # Setup
    user = create_test_user()

    # Action
    result = some_function(user)

    # Assertion
    self.assertEqual(result, expected_value)
```
